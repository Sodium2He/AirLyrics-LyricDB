AirLyrics LyricDB displays synced floating lyrics using song metadata from the player. It is built for Windows WebDAV music libraries and Symfonium.

Features:
• A Windows tool extracts song metadata and embedded lyrics into a LyricDB catalog
• Android synchronizes the catalog through WebDAV or imports it from a local directory
• Lyrics matching uses player metadata, with line-synced LRC and word-by-word timing
• Separate text size and opacity controls for original lyrics and translations
• Long-line scrolling, animated background resizing, and lyric line filtering
• Adjustable floating window position, appearance, and display scope

Privacy:
Notification access detects media playback on the device. WebDAV sync sends requests and credentials to the configured server and downloads the lyrics catalog.
